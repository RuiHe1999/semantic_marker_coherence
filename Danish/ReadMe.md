# Danish coherence corpus 

The coherence corpus in Danish is the DDisCo dataset available at [DaNLP](https://danlp-alexandra.readthedocs.io/en/latest/index.html). The dataset can also be downloaded directly: http://danlp-downloads.alexandra.dk/datasets/ddisco.zip. We also deposit the data here. 

Once you download the dataset, unzip it to a folder named "ddisco", where you can find one tsv file for train data and another for test data. We used both in this study. Then you can run the extract_Data.py to organize the data into a csv file named "summary.csv".
