# English coherence corpus

The coherence corpus in English is the Grammarly Corpus of Discourse Coherence (GCDC) dataset available at https://github.com/aylai/GCDC-corpus.

Once you have gained access to the GCDC corpus, download the nice files (eight csv files and one readme) to the GCDC_Corpus_v2. Then you can run the extract_Data.py to organize the data into a csv file named "summary.csv".
