# Chinese coherence corpus

The coherence corpus in Chinese is the Chinese Essay Discourse Coherence Corpus (CEDCC) corpus. We used both the train and test sets,  available at https://github.com/cubenlp/CEDCC_corpus/tree/main/baselines/DiscourseCoherence/data. The json files are also deposited here. 

The extract_data.py extracted data from the json files and organized them into a dataframe saved in summary.csv.
